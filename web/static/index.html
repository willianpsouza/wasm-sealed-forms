Sealed PII Form end-to-end

Formulário de seguro com muitos dados pessoais. O navegador assina e sela o JSON em WASM antes de enviar. Um API gateway / proxy reverso no caminho só vê texto cifrado — apenas o backend consegue abrir.

Demo. A chave de assinatura embutida no .wasm é extraível e não autentica o remetente. A garantia real é confidencialidade: só o backend (dono da chave x25519) descriptografa. Veja o README.
